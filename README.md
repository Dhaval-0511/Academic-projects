# Academic Projects

> A curated portfolio of projects I designed, developed, and explored during my college journey.

This repository is an index of my academic projects and practical learning work. Each entry includes a short overview, the source code, and a live demo when a verified deployment is available. The original implementation remains in the linked project repository.

## Projects

Projects are listed from newest to oldest based on the latest repository activity.

### 1. Smart Restaurant Operations & POS Platform

**Repository:** [Smart-Restaurant-POS](https://github.com/Dhaval-0511/Smart-Restaurant-POS)  
**Live demo:** [smart-restaurant-pos-client.vercel.app](https://smart-restaurant-pos-client.vercel.app)

A full restaurant operations platform that combines point-of-sale workflows, dine-in/takeaway/delivery order handling, table management, a real-time kitchen display system, recipe and ingredient inventory, procurement, supplier management, analytics, and AI/ML decision support.

**Focus:** Full-stack product development, restaurant workflows, role-based access, dashboards, and deployment.

### 2. Sorting Algorithm Visualizer

**Repository:** [Sorting-Viewer](https://github.com/Dhaval-0511/Sorting-Viewer)

An interactive educational tool that visualizes sorting algorithms step by step. It helps learners understand how arrays change during sorting through live status updates and final results.

**Focus:** Data structures and algorithms, visualization, algorithm comparison, and interactive frontend development.

---

### 3. SynoVita — Personal Health Tracker

**Repository:** [SynoVita](https://github.com/Dhaval-0511/SynoVita)

A personal health platform for managing patient and doctor workflows, health information, and administrative operations. The application includes role-specific experiences, REST APIs, authentication, and real-time communication support.

**Focus:** Healthcare applications, React, TypeScript, Express, SQLite, Vite, Socket.IO, and role-based workflows.

---

### 4. Rentoura — Rental Operations Platform

**Repository:** [Rentoura](https://github.com/Dhaval-0511/Rentoura)

A modern rental business management platform covering product catalogs, inventory, quotations, rental orders, GST-compliant invoices, pickup and return operations, customer management, dashboards, and reports.

**Focus:** Business process design, React, TypeScript, Vite, Tailwind CSS, shadcn/ui, and responsive interfaces.

---

### 5. CARS — Clinic Appointment & Record System

**Repository:** [CARS](https://github.com/Dhaval-0511/CARS)

A clinic management system for authentication, role-based access, doctor profiles, appointment booking, availability slots, and medical records. It includes a .NET Web API, database-backed workflows, and a browser-based frontend.

**Focus:** ASP.NET/.NET Web API, JWT authentication, healthcare workflows, relational data modeling, and API development.

---

### 6. Food Calorie Estimator

**Repository:** [Food-Calorie-Estimator](https://github.com/Dhaval-0511/Food-Calorie-Estimator)

An end-to-end machine-learning application that classifies food images and estimates calories. The project covers model training, transfer learning with MobileNetV2, Flask-based inference, and containerized deployment with Docker.

**Focus:** Python, TensorFlow, computer vision, transfer learning, Flask, ML pipelines, and Docker.

---

### 7. World Happiness Report Analysis

**Repository:** [World-Happiness-Report-](https://github.com/Dhaval-0511/World-Happiness-Report-)

An R-based data analysis project using World Happiness Report data. It cleans and visualizes happiness trends by country and year, then applies linear and polynomial regression to study socio-economic factors associated with global happiness.

**Focus:** Data cleaning, exploratory data analysis, visualization, statistical modeling, and R programming.

---

### 8. Healthcare Website

**Repository:** [Healthcare-Website](https://github.com/Dhaval-0511/Healthcare-Website)

A healthcare-focused website designed to help users explore health information and track their personal health. This project was part of my practical frontend and web development learning journey.

**Focus:** Web development, healthcare-focused user experience, responsive design, and frontend implementation.
